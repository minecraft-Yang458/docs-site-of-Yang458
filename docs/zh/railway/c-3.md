# 第3章 尸潮（二）

孙副连长走上2号墙北段的时候，墙头上已经站满了人。

2号墙比1号墙高，比1号墙厚，火力配置也比1号墙强。八座双联装30mm机炮已经就位，炮口对准了1号墙方向。120mm迫榴炮架在墙后的炮位上，炮手蹲在炮位里，等射击诸元。155mm加榴炮在更后方，但炮弹不多了。孙副连长知道，2号墙的弹药储备比1号墙多，但也撑不了太久。

1号墙方向，尸群正在翻越废墟。

最先翻过来的是暴走者。这些感染者速度快，动作猛，踩着1号墙的碎石堆往上涌，第一个冲上了墙头。然后是普通感染者，密密麻麻，像蚂蚁一样翻过墙体，从缺口处涌进来。1号墙与2号墙之间的缓冲地带，本来是一片荒地，此刻正在被尸群填满。

孙副连长举起望远镜。1号墙到2号墙之间大约三公里，尸群已经填满了将近一公里。剩下的两公里，按尸群的速度，大约需要四十分钟。他放下望远镜，拿起通讯器：“2号墙北段各炮位注意，我是孙副连长。尸群已越过1号墙，正在向2号墙推进。距离两公里，速度每小时三公里。预计四十分钟后接触。120迫榴炮位，准备射击诸元。30mm机炮位，等尸群进入三公里再开火。155炮位，还有多少弹？”

155炮位回话：“报告，还剩四十发。”

“省着打。等尸群密集区进入射程，一次齐射。不要零敲碎打。”

“明白。”

孙副连长放下通讯器，靠在墙垛上，喘了口气。他低头看了一眼自己的手——手指还在抖。他把手压在墙垛上，稳住。

四十分钟后，尸群前锋进入三公里。

30mm机炮开火。八座双联装机炮同时射击，炮口喷出的火舌在灰暗的晨雾中连成一条线。机炮是直射武器，弹道平直，穿甲弹和高爆弹直接扫进尸群前锋。一排排尸群被拦腰打断，尸体铺满了缓冲区。但后面的尸群踩着前面的尸体继续往前涌。

孙副连长盯着望远镜。尸群没有退，和1号墙一样。他拿起通讯器：“155炮位，放。”

四门155mm加榴炮齐射。炮弹划过晨空，砸在尸群中段，连成一片火墙。爆炸声从前方传来，闷闷的，像是有人在远处捶墙。火墙在尸群中炸开，成片尸群倒下。但后面的尸群踩着前面的尸体继续往前涌。155炮又打了两轮，四十发炮弹打光了。炮手从炮位上站起来，摊了摊手。孙副连长拿起通讯器：“155炮位撤到3号墙，把炮带回去。”

尸群推进到两公里。120迫榴炮开火。八门迫榴炮，炮弹吊射，落在尸群前锋，爆炸的火光一闪一闪。迫榴炮的射速比加榴炮快，弹道更弯，更适合打近距离的密集目标。尸群继续推进，一公里。机炮和迫榴炮同时开火，火力全开。

但尸群太多了。

1号墙方向的缺口还在扩大，更多的尸群正在翻越废墟，涌入缓冲区。孙副连长看着望远镜，缓冲区的尸群已经填满了将近两公里，前锋离2号墙只有不到五百米。他拿起通讯器：“指挥部，北墙孙副连长报告。2号墙北段弹药储备百分之四十，尸群前锋距墙五百米，请求增援。”

指挥部回话：“孙副连长，指挥部收到。丰镐弹药专列被堵在神州，无法抵达。2号墙弹药储备就是全部。省着用。”

孙副连长攥着通讯器，没说话。他放下通讯器，拿起望远镜。尸群还在涌来。他转身对墙头上的守军喊：“各炮位注意，弹药省着用！机炮打点射，不要连发！迫榴炮只打密集区！手雷等尸群到墙根再扔！”

守军开始点射。机炮的嘶吼变成了一阵阵短促的点射，像是喘不上气的人在苟延残喘。迫榴炮的射击频率也降了下来，炮手们仔细瞄准，每一发都往尸群最密的地方打。手雷攒着，等尸群涌到墙根才扔。

一个小时后，2号墙的弹药储备降到百分之十。

然后，弹药库方向传来一声巨响。

孙副连长猛地转头。2号墙中段，一股黑烟冲天而起，混凝土碎块飞溅。弹药库的隔离门被炸开了，火光从里面喷出来。他抓起通讯器：“指挥部！2号墙弹药库被引爆！重复，2号墙弹药库被引爆！”

指挥部回话，声音很急：“孙副连长，指挥部收到。弹药库怎么被引爆的？”

“不知道，但弹药库没了，剩下的弹药撑不了多久。”

指挥部那边沉默了几秒。然后回话：“孙副连长，指挥部命令：2号墙，死守。铁北站还在撤离，3号墙还在布防，地下城闸门还没关。你们多守一分钟，就多撤一列车人。打到最后一发子弹。”

孙副连长攥着通讯器，指节发白。他看了一眼墙头——守军还在打，机炮还在响，但弹药库没了，弹药补给断了。他咬了咬牙，抓起通讯器拨到全墙频道：

“2号墙各炮位注意，我是孙副连长。指挥部命令：死守。没有撤退命令，谁也不许退。弹药打光了，用刺刀。刺刀断了，用钢筋。钢筋弯了，用牙咬。铁北站还在撤人，3号墙还在布防。我们多守一分钟，就多撤一列车人。听明白没有？”

通讯器里陆续传来回应：“北段明白。”“中段明白。”“南段明白。”

孙副连长放下通讯器，抄起步枪。墙头上的守军继续打。机炮打光了最后一发弹药，炮手从炮位上站起来，抄起刺刀。迫榴炮打光了最后一发炮弹，炮手从炮位上跳下来，抄起钢筋。手雷扔完了，守军开始用瓦刀、用铁锹、用混凝土碎块。

尸群翻过墙头。

孙副连长亲手用钢筋捅穿了三只尸群。钢筋弯了，他换了瓦刀。瓦刀断了，他捡起一块混凝土碎块，砸。他身边的守军一个接一个倒下，但没有人后退。他们堵在墙头，和翻过墙头的尸群肉搏。2号墙的北段墙头上，喊杀声、嚎叫声、金属碰撞声混成一片。

两个小时后，铁北站方向传来汽笛声。一列撤离列车正在出站。又过了半小时，第二列。第三列。

四个小时后，铁北站最后一列撤离列车发出汽笛。指挥部下令：“孙副连长，2号墙，撤。”

孙副连长带着残部撤下2号墙。墙头上，守军的尸体和尸群的尸体混在一起，堆满了整个北段。他跑下楼梯，跑进2号墙与3号墙之间的生活区。生活区里已经空了，所有人都撤进了3号墙。他跑过三号楼工地——就是他早上砌墙的地方。脚手架上还挂着那桶没倒完的水泥，灰浆已经干了，凝固在桶壁上。他跑过砂浆站，跑过工棚，跑过宿舍区。

身后，2号墙的最后一挺机炮打光了弹药。然后，2号墙安静了。

孙副连长跑进3号墙闸口的时候，闸门正在下降。守军正在关闸门，他最后一个冲进去，闸门在他身后合拢，发出一声沉闷的巨响。他靠在闸门上，喘着气。他抬起头，看见3号墙的墙头上，守军正在就位，炮口对准了2号墙方向。2号墙方向，尸群正在翻越墙头，涌入生活区。

他拿起通讯器：“指挥部，北墙孙副连长报告。2号墙守军已撤入3号墙。2号墙，失守。我部保留了约四成战斗人员，可在3号墙继续作战。”

指挥部回话：“收到。2号墙残部编入3号墙防御序列。孙副连长，你负责3号墙北段指挥。”

孙副连长放下通讯器，靠在闸门上。他低头看了一眼自己——工装破了好几处，左臂上缠着临时包扎的布条，渗着血。2号墙的守军，四成伤亡，剩下的人挤在闸门内侧，有的坐着喘气，有的在检查武器，有的靠着墙不说话。

他站直身子，走到3号墙北段的楼梯口。楼梯上人来人往，弹药手在搬弹药箱，医护兵在抬伤员，通讯兵在拉电话线。他往上走了几步，停下来，回头看了一眼闸门。闸门外面，2号墙方向的尸群嚎叫声越来越响，越来越近。

他靠在楼梯扶手上，摸出烟盒。空的。他把烟盒攥成一团，扔在地上。然后他从口袋里摸出半截烟屁股——在2号墙上没来得及点的，一直揣着。他叼在嘴上，没点。

“孙副连长。”一个声音从身后传来。

他转头。是3号墙北段的守军指挥官，姓吴，吴连长。吴连长走过来，拍了拍他的肩膀：“你那边还剩多少人？”

“不到两百。”孙副连长说。

吴连长沉默了一下：“2号墙守了四个小时，铁北站撤出了四列车。你们守得够本了。”

孙副连长没说话。

吴连长看了一眼他嘴上的烟屁股：“没火？”

孙副连长摇头。

吴连长从口袋里摸出火柴，划了一根，递过去。孙副连长凑上去，点着了。烟屁股烧得很快，他抽了一口，呛了一下，咳了两声。

“上墙吧。”吴连长说，“3号墙北段，你的人编入我的序列。你负责左翼。”

孙副连长把烟屁股掐灭，塞回口袋。他看了一眼3号墙的墙头——守军正在搬运弹药箱，炮手在调整机炮角度。墙外，2号墙方向的尸群已经翻过墙头，正在朝3号墙涌来。3号墙的机炮还没开火。孙副连长知道，等尸群进入射程，3号墙也会变成2号墙，然后变成1号墙，最后变成铁北陷落的最后一个句号。

他走上楼梯，踏上3号墙北段的墙头。墙头上，守军给他让出一个位置。他站在墙垛后面，看着墙外涌来的尸群，把步枪架在墙垛上。

旁边的吴连长问：“你那边的人，还能打吗？”

孙副连长说：“能打。打到最后一个人。”

吴连长没再说话。墙外，尸群进入三公里。3号墙的机炮开火了。
