# 第1章 铁北基地

> 人类纪元323年3月23日 亚洲 铁北基地

林燚照常从他的破旧木板床上醒来，简单的洗漱过后，他戴上工程帽轻车熟路的走出宿舍，周师傅照常倚在楼梯口等着他。“走快点，小子！我们要迟到了！”周师傅骂骂咧咧的带着林燚推开门来到了一个房间，只见第二工班的众人正在等待他们。

领班赵大工见人齐了，开口说道：“人齐了啊，那我来分配一下今天的任务。”他走到墙上挂的铁北住宅区规划图前，拿粉笔在规划图上画了几个圈：“三号楼东墙，昨天浇到第四段，今天接着浇第五段。老周，你带林燚、小张，上东墙。模板支好了，钢筋绑完了，今天就是浇筑，十五米。老孙，你带几个人去西墙，把昨天的模板拆了，养护浇水。老李，你带两个人去搅拌站，把今天要用的混凝土配好拉过来。大刘，你去钢筋堆场，把明天要用的钢筋先搬过来，别到时候抓瞎。”

随着赵大工将任务分配给众人，众人走出房间奔向各自的岗位。

工地上，铁北的早晨刚刚开始。远处，2号墙的轮廓在灰霾中若隐若现，墙头的探照灯还在旋转，光柱扫过荒地，扫过1号墙方向，那里隐约传来零星的枪声——外围哨所又在清理游荡的散尸。更远处，铁北站的汽笛声穿透晨雾，一列装甲列车正缓缓驶出编组站，H-01X车头喷出的白烟被风吹散，车身上“丰镐—铁北”的编号一闪而过。那列车装满了弹药，从丰镐来，要在铁北卸货，再装上铁北产的装甲板和食品罐头，发往龙脊。

一切都是那么平常。

“别傻站着呀，赶紧去搅拌站推一车水泥过来！”周师傅的话语使林燚的目光收回，赶忙推上推车前往搅拌站。

搅拌站设在生活区中部，紧挨着一条窄轨支线——从铁北站卸下来的散装水泥和砂石，用小型轨道车拉到这儿，直接进料仓。林燚到的时候，老李已经在了，搅拌机轰隆隆转着，水泥已经拌好了，浓稠的灰浆在出料口后面翻滚。老李蹲在旁边抽烟，面前摊着配比单。

林燚把推车停到出料口底下，伸手拉开闸门。水泥浆涌出来，灰暗、浓稠，落在推车里啪啪作响，溅起几点灰星子。他盯着推车，满了就关闸。一车水泥，几百斤，推起来沉，但省了和料的功夫。他推着车往东墙走，车轮碾过碎石，哐当哐当响。四五百米的路，六七分钟就到。

林燚推着水泥车到东墙楼下的时候，周师傅正在站在脚手架上，手里攥着线锤，正校昨天砌到第四层的那截墙。脚手架是钢管搭的，两层，跳板铺在横杆上，周师傅站的那层刚好齐第四层砖的标高。“来了？”周师傅头也不回，“水泥给我。”

林燚把推车停到灰槽旁边，从工具堆里拎起一把铁锹，铲了一锹水泥装进泥桶，拎着桶走到脚手架下，递给小张，小张再递到周师傅手边。周师傅蹲下来，瓦刀伸进桶里铲起一坨，抹在砖面上。砖一放，一压，一挤。第五层第一块砖稳稳坐上了墙。

小张在下面递砖，林燚守在旁边——桶里水泥快见底了，他转身从推车里再铲一桶拎过来。三人配合，一层砖很快砌上去。控制线前几天就弹过了，皮数杆还钉在两头，白线绷着，周师傅跟着线走，砖砌得笔直。

“看好了，”周师傅头也不抬，“灰缝匀，砖放平，线绷紧。砌歪了，楼板一压就裂。”

林燚站在下面看着。他干了几个月，这些工序早就熟。但周师傅每次还是说，他还是听。

与此同时，铁北基地1号墙北墙作战值班室

“报告！有大量丧尸向北墙方向移动！当前方位北偏西10°12'32″约12.3km处！”雷达员惊恐的报告。

孙副连长手里的搪瓷缸“咣”一声砸在操作台上，茶水溅了一桌。他三步跨到雷达屏幕前，那条黑线正在变粗、变亮，回波信号密集得几乎连成一片矩形。

“数量？”

“初判超过十万，后续还在不断涌入探测范围！”

副连长抓起无线电：“北墙值班室呼叫指挥部！北面发现大规模尸群，方位北偏西10°，距离十二点三公里，数量十万以上，正在向我方高速移动！”

话筒那头只沉默了半秒：“指挥部收到。启动一级战备响应。北墙继续追踪，每三十秒报一次方位和距离。弹药储备还有多少？”

“1号墙弹药储备百分之七十。”

指挥部那边又是一阵沉默，比刚才更长。然后回话：“北墙，指挥部明白。你们的判断？”

孙副连长咬了咬牙：“B级墙设计标准是抵御五万规模尸潮。现在来的，十万以上，还在增加。1号墙挡不住。”

“收到。”指挥部的声音很平，“继续观察。增援的事，指挥部来协调。”

话筒挂断。孙副连长放下话筒，转身对值班室全体人员说：“都听见了。指挥部已经启动一级战备。我们的任务，是盯住尸群，每三十秒报一次方位距离，给炮位提供射击诸元。1号墙能拖多久拖多久，等指挥部调增援。”

小刘站在旁边，脸白了：“老孙，增援……来得及吗？”

孙副连长没回答。他走到观察窗前，举起望远镜。北面荒原的尽头，灰蒙蒙的晨雾里，那条黑线已经变成了一道黑墙，正在缓缓推进。黑墙前面，几个外围哨所的游动哨正在往回跑。黑墙后面，还有更多的黑墙。
