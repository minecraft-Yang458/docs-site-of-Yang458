# 第2章 尸潮(一)

雷达员报告尸群位置后不到一分钟，孙副连长就拿起通讯器：“155炮位，开火。”

四门155mm加榴炮同时射击，炮弹拖着曳光划过晨空，砸在十二公里外的尸群纵深，连成一片火墙。爆炸声隔着十二公里传过来，闷闷的，像是有人在远处捶墙。孙副连长举起望远镜，火墙在尸群中段炸开，尸群成片倒下，但后面的尸群踩着前面的尸体继续往前涌。

“第二轮，放。”

155炮装填，第二轮齐射，第三轮齐射。三轮打完，尸群前锋推进到八公里。孙副连长放下望远镜，拿起通讯器：“120迫榴炮位，准备。”

尸群推进到七公里，120mm迫榴炮开火。八门迫榴炮，炮弹吊射，落在尸群前锋，爆炸的火光一闪一闪。迫榴炮的射速比加榴炮快，弹道更弯，更适合打近距离的密集目标。尸群继续推进，六公里，五公里。迫榴炮持续射击，155炮阵地装填第四轮。

尸群推进到三公里，30mm机炮开火。八座双联装30mm机炮同时射击，枪管喷出的火舌在灰暗的晨雾中连成一条线。尸群成片倒下。但后面的尸群踩着前面的尸体继续往前涌。155炮装填，第五轮，第六轮。120迫榴炮继续射击。机炮的枪管打红了，副射手拎着水桶往枪管上浇。弹药手搬弹药箱，一箱一箱往炮位上送。

尸群推进到一公里，1号墙火力全开。机炮平射，迫榴炮吊射，加榴炮纵深覆盖。1号墙前，尸群成片倒下，尸体堆成了斜坡。

孙副连长盯着望远镜。尸群没有退。正常尸潮，炮火一压就散了，但这次不一样。尸群在墙外五百米处停了一下，然后又开始推进。

---

与此同时，铁北驻军指挥部。

值班参谋姓秦，秦参谋，四十多岁，在铁北驻军干了快二十年。他接到孙副连长的报告后，第一时间拨通了龙脊的加密专线。

“龙脊，龙脊，铁北紧急呼叫。北面尸群规模十万以上，方位北偏西10°，距离十二点三公里，速度每小时三公里。请求喀秋莎火箭炮火力支援，坐标已加密发送。请立即授权开火。”

龙脊调度中心的值班员声音平稳：“铁北，龙脊收到。增援请求已记录。跨洲火力支援需经联盟最高军事委员会审批。正在上报。”

“上报审批？”秦参谋压着火，“尸群已经在眼前了，十二公里，火箭炮飞过来几分钟的事，你跟我说审批？”

“流程规定，铁北。我理解你的处境，但流程就是流程。龙脊会加急。”

通讯挂断。秦参谋把话筒砸在操作台上，骂了一句。

他拨通了铁北驻军司令部的内部频道：“司令部，值班室报告。已向龙脊请求喀秋莎支援，龙脊要求走审批流程。我请求司令部直接联系龙脊，跳过程序。”

司令部回话：“收到。司令部来协调。”

秦参谋放下话筒，盯着屏幕。尸群在推进。十二公里。十一公里。十公里。他每三十秒收到一次北墙值班室的报告，每三十秒把报告转发给龙脊。每转发一次，他都问一句：“审批到哪了？”

龙脊的回答始终一样：“正在处理。”

二十分钟后，秦参谋再次拨通龙脊专线：“龙脊，铁北再次请求紧急火力支援。尸群距离九公里，155炮位已经接战。审批还要多久？”

“铁北，龙脊正在协调最高军事委员会召开紧急会议。请耐心等待。”

“耐心？”秦参谋的声音提高了，“尸群每小时推进三公里，十二公里到墙下只要四个小时。你们的紧急会议要开多久？”

“这个……我无法给出确切时间。”

又过了二十分钟。尸群到七公里。秦参谋再次拨通龙脊：“龙脊，铁北报告。尸群七公里，120迫榴炮位已接战。审批到底到哪了？”

“铁北，最高军事委员会紧急会议已召集，目前正在表决中。请再坚持一下。”

“再坚持一下？”秦参谋攥着话筒，急得都想骂娘，“你们知不知道铁北的1号墙是什么级别？B级！设计标准是五万尸潮！现在来的十万以上，你让我再坚持一下？”

“铁北，龙脊理解你们的处境——”

“你不理解。”秦参谋打断他，“你坐在龙脊的地下指挥中心，隔着几千公里，你不理解。”

通讯挂断。尸群到五公里。

---


一个半小时后，1号墙的弹药储备降到百分之三十。155炮彻底哑了，最后一轮齐射打光了所有弹药。120迫榴炮的炮弹也见了底。只剩下30mm机炮还在响，但枪声开始稀了，不再是连续的嘶吼，而是一阵一阵的点射。孙副连长看着望远镜，尸群的尸体斜坡已经堆到了墙根，后面的尸群踩着斜坡往上爬，离墙头只有不到五米。守军开始扔手雷，爆炸的火光在墙头炸开。

孙副连长放下望远镜，拿起通讯器：“指挥部，北墙值班室。1号墙弹药储备百分之十，机炮即将断弹，手雷耗尽。尸群尸体斜坡已堆至墙根，守军快顶不住了。”

指挥部那边沉默了几秒。然后回话，声音很沉：“北墙，指挥部命令：1号墙守军立即撤出，退入2号墙。重复，立即撤出，退入2号墙。2号墙炮位全力掩护。”

孙副连长攥着通讯器，指节发白。他看了一眼墙头，守军还在打，机炮还在响，但所有人都知道，打不下去了。弹药没了，人还在，但人不能拿肉身去挡尸群。

他咬了咬牙，抓起通讯器拨到全墙频道：“北墙各炮位注意，我是孙副连长。指挥部命令：1号墙守军立即撤出，退入2号墙。各炮位交替掩护，弹药打光的先撤，还有弹的掩护。不要恋战，不要硬拼。撤到2号墙，我们还能守住。撤慢了，全军覆没。听明白没有？”

通讯器里陆续传来回应：“一号炮位明白。”“二号炮位明白。”“三号炮位明白。”

“撤。”孙副连长放下通讯器，转身对值班室里的人喊，“走！撤到2号墙！”

他拎起步枪，冲出值班室。外面的走廊里全是人，守军、通讯兵、后勤兵，所有人都在往南跑。北面的尸群正在翻越墙头，嚎叫声越来越近。

孙副连长带着残部跑出1号墙的后门，跑进1号墙与2号墙之间的缓冲地带。身后，1号墙的机炮还在响，还有弹的炮位在掩护撤退。他跑了两百米，跑进2号墙的闸口。守军正在关闸门，他最后一个冲进去，闸门在他身后合拢，发出一声沉闷的巨响。

他靠在闸门上，喘着气，手里的步枪还在发抖。他抬起头，看见2号墙的墙头上，守军正在就位，炮口对准了1号墙方向。1号墙方向，机炮声停了。最后一挺机炮打光了弹药。然后，1号墙安静了。

孙副连长拿起通讯器：“指挥部，北墙值班室。1号墙守军已撤入2号墙。1号墙，失守。但我部保留了约六成战斗人员，可在2号墙继续作战。”

指挥部回话：“收到。北墙残部编入2号墙防御序列。孙远副连长，你负责2号墙北段指挥。”

孙副连长放下通讯器，靠在闸门上，闭上眼睛。他想起1号墙的弹药库——如果弹药再多一点，如果再撑一个小时，如果喀秋莎早来半个小时。但战场上没有如果。

他睁开眼睛，拿起步枪，走向2号墙北段的楼梯。

“走，上墙。”
