# 第一卷：计算机理论[^1]
::: info 卷首语
理论，往往意味着抽象、枯燥、离实践很远。但在本书的语境里，理论有另一层含义：它是地图，是骨架，是你在动手之前需要先建立的整体认知。

在写第一行代码、点亮第一颗LED之前，我们先要回答一个问题：计算机到底是什么。这个问题的答案，比多数人以为的要宽。电子表是计算机，洗衣机是计算机，公交卡也是计算机。本卷将逐层展开这个定义，把计算机从“桌上那台机器”的狭义理解中释放出来。

本卷以理论为主，动手内容较少。这是有意的安排。先看清整片森林，再去种第一棵树，后续的路会走得更稳。
:::
学习完本卷后，你将知道：
- 计算机的定义远比“电脑”宽泛，以及为什么电子表、洗衣机、公交卡都算计算机

- 计算机的五大基本组成部件，以及它们各自负责什么

- 数据在计算机中如何表示，为什么只有 0 和 1

- 硬件与软件的分工，以及它们如何协作

- 一门编程语言从写下到运行，中间经历了什么

- 计算的本质是什么，以及它的边界在哪里

[^1]:本书仍然延续原书传统，使用注释
